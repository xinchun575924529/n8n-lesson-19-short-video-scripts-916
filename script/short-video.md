# 课程宣发口播脚本（约 60 秒）

## 口播稿

还在一条一条手写短视频脚本吗？

给你一个接口，POST 一个主题进去，AI 直接吐出整套脚本包：标题、两个开场 hook、四镜头分镜、口播稿、话题标签，连抖音、YouTube、Instagram 三个平台的发布文案都各写一份。

这还没完——写好的文案发给第二个接口，自动体检：词数超没超、标题长不长、有没有违规绝对化用语，一秒钟出报告。

确认没问题，第三个接口提交渲染，第四个接口凭任务号取成片。

全程两个付费点我们都给你换成了免费替身：OpenAI 换 DeepSeek，渲染可以直接本地 ffmpeg 出片。零元跑通全链路。

更值钱的是这个模板的护栏设计：入参白名单、双人审批闸门、错误分级、异步轮询——教科书级别的 API 工作流姿势，学会能套在任何 AI 产品上。
