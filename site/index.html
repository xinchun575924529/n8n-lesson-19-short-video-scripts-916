这是什么

把「AI 写短视频脚本 → 人工审 → 渲染 9:16 → 取成片」做成四个标准 HTTP 接口的生产级 webhook 工作流。前端/App/机器人只管 POST，工作流内部做校验、调 AI、人工闸门、错误分级。

四个接口

POST /webhook {"action":"draft"} → 主题进，整套脚本包出（标题/双hook/4分镜/口播/三平台文案） POST /webhook {"action":"audit"} → 文案进，确定性体检报告出（词数/标题/违规词） POST /webhook {"action":"render"} → 双闸门通过，提交 9:16 渲染，拿任务号 POST /webhook {"action":"status"} → 任务号进，成片 URL 出

为什么值得学

  • ⭐ 教科书级护栏：入参白名单 → LLM 输出 schema 强校验 → audit 确定性预检 → 人工双闸门，四层递进
  • ⭐ 错误分级范式：调用方错 400 / 上游故障 502，API 语义干净
  • ⭐ 无状态异步设计：render 拿 id、status 轮询，长任务 API 标准形态
  • 实锤坑「LLM 词数漂移」：prompt 软约束被无视，护栏正确兜底——141 词被告警的活证据
